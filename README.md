# Сайт строительной компании

Три публичные страницы и админ-панель:

| Адрес | Что там |
|---|---|
| `/` | Главная: информация о компании, цифры, преимущества, популярные проекты, **калькулятор стоимости**, **форма заявки** |
| `/projects` | Каталог проектов домов (фото, характеристики, цена, фильтр по технологии); `/projects/<id>` — страница проекта с галереей |
| `/video` | **Камеры на объектах** (онлайн) + видео по разделам: *видео проектов*, *отзывы*, *видео работ* |
| `/admin` | Админ-панель (вход по паролю) |

## Админ-панель

- **Заявки** — все обращения с сайта (форма, «Заказать звонок», калькулятор с приложенным расчётом), статусы «новая / в работе / обработана».
- **Проекты домов** — добавить/изменить/скрыть/удалить проект, загрузить сразу несколько фото (перетаскиванием), менять порядок фото, первое фото — обложка.
- **Видео** — загрузка файла (MP4 до 1 ГБ, с индикатором загрузки) или ссылка на YouTube / Rutube / VK; выбор раздела, обложка.
- **Камеры** — ссылка на трансляцию: плеер облачного сервиса (Ivideon, RTSP.me, IPEYE и т.п.), YouTube/VK Live, HLS-поток `.m3u8` или JPEG-снимок (обновляется каждые 5 с). Подсказка по подключению — прямо в админке.
- **Настройки** — название, слоган, текст «О компании», контакты, цифры, преимущества и **все цены/коэффициенты калькулятора**.

> **Про камеры.** Браузеры не показывают RTSP-поток IP-камеры напрямую. Самый простой путь — подключить камеру к облачному сервису и вставить его ссылку «для встраивания». Свой вариант — медиасервер (go2rtc / MediaMTX), отдающий HLS.

## Запуск

Нужен Node.js 18+.

```bash
npm install
cp .env.example .env     # и задайте ADMIN_PASSWORD
npm start                # http://localhost:3000, админка — /admin
```

Переменные `.env`:

- `ADMIN_PASSWORD` — пароль админки (**обязательно поменять**);
- `PORT` — порт (по умолчанию 3000);
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — необязательно: новые заявки будут приходить в Telegram.

## Фирменный стиль (брендбук)

Все цвета, шрифты и скругления — переменные в начале `public/css/style.css` (блок `:root`).
Логотип — `public/img/logo.svg`, шрифты подключаются в `<head>` страниц. Замените их значениями из брендбука — изменится весь сайт.

## Анимации и оформление

- Плавная инерционная прокрутка ([Lenis](https://github.com/darkroomengineering/lenis)), появление блоков при прокрутке, параллакс фото.
- Первый экран: заголовок появляется по словам, счётчики цифр, медленный «наезд» фона, анимированная «чертёжная» сетка.
- Шапка прозрачная над первым экраном и прячется при прокрутке вниз; полоса прогресса чтения; кнопка «наверх» с кольцом прогресса.
- Кнопки с бликом и «волной» при нажатии, 3D-наклон карточек проектов, плавный пересчёт суммы в калькуляторе, бегущая строка, блок «Этапы работы».
- Если у посетителя в системе включено «уменьшить движение», анимации отключаются.

Код анимаций — `public/js/motion.js`, стили — `public/css/style.css`.
Библиотеки (Lenis, hls.js) ставятся через `npm install` и отдаются с вашего сервера (`/vendor/…`), без внешних CDN.

## Хранение данных и бэкап

- Данные (настройки, проекты, видео, камеры, заявки) — `data/db.json` (создаётся при первом запуске).
- Загруженные фото и видео — `public/uploads/`.

Для резервной копии достаточно сохранить эти две папки.

## Размещение

Подойдёт любой VPS с Node.js (например, через `pm2 start server.js`) за nginx с HTTPS.
В nginx увеличьте лимит загрузки для видео: `client_max_body_size 1100m;`.
