# Domus — сайт для продажи недвижимости

Одностраничный адаптивный сайт агентства недвижимости на чистом HTML/CSS/JS.

## Запуск

Просто откройте `index.html` в браузере. Это один самодостаточный файл: стили, скрипты и библиотеки
встроены внутрь, поэтому его можно скачать отдельно или разместить на любом хостинге.
Для фотографий и шрифтов нужен интернет.

## Как вносить правки

Исходники лежат в папке `src/`:

- `src/index.html` — разметка и тексты
- `src/styles.css` — оформление
- `src/script.js` — объекты каталога и анимации
- `src/vendor/` — библиотеки GSAP и Lenis

После правок соберите итоговый файл:

```bash
python3 build.py
```

## Что есть на сайте

- Главный экран «строим дом»: при прокрутке на чертёжной сетке рисуется дом — фундамент, стены, крыша, окна загораются светом, затем фото проявляется в силуэте дома и раскрывается на весь экран
- Поиск (купить / арендовать, тип, район, комнаты)
- Каталог объектов с фильтрами, избранным и окном с подробностями
- Преимущества, этапы работы, отзывы
- Форма заявки с проверкой полей и уведомлением
- Районы — горизонтальная галерея, которая листается при прокрутке страницы
- Мобильное меню, счётчики, кнопка «наверх» с индикатором прогресса

## Анимации

- Плавная инерционная прокрутка ([Lenis](https://github.com/darkroomengineering/lenis))
- Анимации при прокрутке на [GSAP](https://gsap.com) + ScrollTrigger: заголовки появляются по словам, параллакс фото, бегущая строка реагирует на скорость прокрутки
- Прелоадер, полоса прогресса прокрутки, собственный курсор
- Кнопки: блик, «перекат» текста, волна при клике, «магнитный» эффект; 3D-наклон карточек

Библиотеки встроены в `index.html`, интернет для них не нужен. Если они не загрузятся или у посетителя
в системе включено «уменьшение движения», сайт работает в упрощённом режиме без тяжёлых анимаций.

## Как изменить объекты

Объекты описаны в массиве `properties` в начале файла `src/script.js`: название, цена, площадь, район, фото и описание.
Контакты (телефон, email, адрес) меняются в `src/index.html`, цвета и шрифты — в переменных в начале `src/styles.css`.
После любых правок запустите `python3 build.py`.
