# Domus — сайт для продажи недвижимости

Одностраничный адаптивный сайт агентства недвижимости на чистом HTML/CSS/JS, без сборки.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Что есть на сайте

- Главный экран с фоновым фото и поиском (купить / арендовать, тип, район, комнаты)
- Каталог объектов с фильтрами, избранным и окном с подробностями
- Преимущества, этапы работы, отзывы
- Форма заявки с проверкой полей и уведомлением
- Мобильное меню, анимации при прокрутке, счётчики

## Как изменить объекты

Объекты описаны в массиве `properties` в начале файла `script.js`: название, цена, площадь, район, фото и описание.
Контакты (телефон, email, адрес) меняются в `index.html`, цвета и шрифты — в переменных в начале `styles.css`.
