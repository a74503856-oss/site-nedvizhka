# Сайт-визитка психолога (Ярославль)

Одностраничный сайт для записи на консультации: первый экран, «Обо мне», запросы, форматы и цены, отзывы, FAQ, контакты с картой и формой заявки.

## Структура

```
index.html     — главная страница
privacy.html   — политика конфиденциальности (нужна для формы по 152-ФЗ)
css/style.css  — стили (адаптив: ПК / планшет / телефон)
js/main.js     — мобильное меню и отправка формы без перезагрузки
send.php       — обработчик формы: e-mail и/или Telegram
config.php     — настройки получателей заявок
robots.txt, sitemap.xml, favicon.svg, .htaccess
```

## Что заменить перед запуском

Все тексты сейчас — образец. Найдите и замените:

- **Имя** «Анна Соколова», образование, опыт, отзывы, цены.
- **Контакты**: `+7 (900) 000-00-00`, `@username`, `hello@example.ru`, адрес `ул. Свободы, 1`.
- **Домен** `https://example.ru/` — в `index.html` (canonical, og, JSON-LD), `robots.txt`, `sitemap.xml`.
- **Карта**: в `index.html` в адресе iframe замените координаты `39.8845,57.6261` (сначала долгота, потом широта) на координаты кабинета — их можно скопировать в Яндекс Картах. Те же координаты укажите в JSON-LD (`geo`).
- **Фото**: положите `img/photo.jpg` (вертикальное, ~800×1000) и замените блок `photo-placeholder` на закомментированный `<img>`. Для превью в соцсетях — `img/og.jpg` 1200×630.
- **privacy.html**: ФИО, статус (самозанятая/ИП), ИНН.

## Настройка формы заявки

Нужен хостинг с PHP 8+ (Beget, Timeweb, REG.RU и т.п. — подойдёт любой тариф).
Откройте `config.php`:

**E-mail.** Укажите `email_to` (куда слать) и `email_from` — ящик на домене сайта (например, `no-reply@ваш-домен.ru`), иначе письма могут попадать в спам.

**Telegram.**
1. В Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. Напишите своему новому боту `/start`.
3. Узнайте свой `chat_id` у [@userinfobot](https://t.me/userinfobot).
4. Вставьте токен и `chat_id` в `config.php`.

Можно включить оба канала одновременно. Токен хранится только на сервере, в браузер он не попадает. Есть защита от спам-ботов (скрытое поле) и проверка согласия на обработку данных. Форма работает и с выключенным JavaScript.

## SEO под «психолог Ярославль»

Уже сделано: `title`/`description` с ключевым запросом, один `h1`, разметка Schema.org (`ProfessionalService` с адресом в Ярославле, телефоном и часами работы), Open Graph, `canonical`, `robots.txt`, `sitemap.xml`, быстрая загрузка без тяжёлых библиотек.

После публикации:
1. Добавьте сайт в [Яндекс Вебмастер](https://webmaster.yandex.ru) и [Google Search Console](https://search.google.com/search-console), отправьте `sitemap.xml`.
2. В Вебмастере укажите регион сайта — Ярославль.
3. Зарегистрируйте организацию в [Яндекс Бизнесе](https://yandex.ru/sprav) и 2ГИС с тем же адресом и телефоном — это сильнее всего влияет на локальную выдачу и показ на картах.
4. Подключите Яндекс Метрику (код вставляется перед `</head>`). Цель на отправку заявки уже предусмотрена: задайте `window.YM_ID = <номер счётчика>` и создайте в Метрике JavaScript-цель `lead`.
5. Попросите клиентов оставлять отзывы в Яндекс Картах.
